# 자동차 평균 대여 기간 구하기

## 문제

`CAR_RENTAL_COMPANY_RENTAL_HISTORY` 테이블에서 평균 대여 기간이 7일 이상인 자동차들의 자동차 ID와 평균 대여 기간(컬럼명: `AVERAGE_DURATION`) 리스트를 출력하는 SQL문을 작성해주세요. 

평균 대여 기간은 소수점 두번째 자리에서 반올림하고, 결과는 평균 대여 기간을 기준으로 내림차순 정렬해주시고, 평균 대여 기간이 같으면 자동차 ID를 기준으로 내림차순 정렬해주세요.

| HISTORY_ID | CAR_ID |	START_DATE | END_DATE |
| :---: | :---: | :---: | :---: |
| 1 | 1 | 2022-09-27 | 2022-10-01 |
| 2 | 1 | 2022-10-03 | 2022-11-04 |
| 3 | 2 | 2022-09-05 | 2022-09-05 |
| 4 | 2 | 2022-09-08 | 2022-09-10 |
| 5 | 3 | 2022-09-16 | 2022-10-15 |
| 6 | 1 | 2022-11-07 | 2022-12-06 |

## 풀이

- ROUND 후 마지막 소수점에 0을 찍기 위해서 TO_CHAR(`값`, 'FM999.0')으로 변환하였다.
  - 9 : 값이 없는 경우 소수점 이상은 공백, 이하는 '0'
  - 0 : 값이 없는 경우 '0'
  - FM : 좌우로 치환도니 소수점 이상의 공백제거

```sql
SELECT
    CAR_ID, 
    TO_CHAR(ROUND(AVG(END_DATE - START_DATE+1), 1), 'FM999.0') AS AVERAGE_DURATION
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
HAVING AVERAGE_DURATION >= 7
ORDER BY ROUND(AVG(END_DATE - START_DATE+1), 1) DESC, CAR_ID DESC
```
